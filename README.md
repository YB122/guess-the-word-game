# Guess the Word Game 🎯

A fun word guessing game built using **HTML, CSS, and JavaScript**.

## 🕹️ How to Play
- You have 6 tries to guess the secret word
- Each word has 6 letters
- Colors give you feedback:
  - 🟨 Correct letter & correct position
  - 🟩 Correct letter but wrong position
  - ⬛ Wrong letter
- You can use hints (limited)

## 💡 Features
- Random word selection
- Word clues system
- Hint system
- Restart game option
- Responsive design
